## Logo

`atlas-logo.png` and `atlas-favicon.png` are the client's existing assets,
copied unmodified from the previous site.

`atlas-logo-reversed.png` is the client-supplied reversed lockup for dark
grounds (white ATLAS, copper OFFTAKE). The only processing applied was
trimming the transparent margin: the supplied file carried 236px of empty
space above and below the artwork, so the mark occupied only 46% of its own
box and rendered small. Trimmed it is 1612x461 (3.5:1); nothing else was
altered.

Note: the copper in this file is #B9501F, which is deeper and redder than the
brand copper #D5771C used for every accent across the site (sampled from the
original logo). The two do not match exactly. See the README for the options.


## Commodity photography — outstanding

Unsplash carries no authentic photography of the refined products these four
cards describe. Searches for them return unrelated material: "lithium
carbonate powder" returns flour and protein powder; "nickel briquettes"
returns barbecue charcoal; "ore concentrate" returns cosmetics.

Rather than substitute something misleading, these keep genuine material
photography and should be replaced with licensed or producer-supplied images:

| Card | Currently shows | Needs |
| --- | --- | --- |
| Copper | Copper conductor (genuine copper metal) | Grade A cathode sheets |
| Cobalt | Cobalt-bearing mineral specimen | Cobalt hydroxide product |
| Nickel | Metal coil | Briquettes / sulphate |
| Rare Earths | Mineral concentrate | Separated oxides |

Lithium uses brine evaporation ponds — genuine lithium production imagery, and
deliberately not a battery. Iron ore uses recognisable iron ore rock.
